# Sample Data

These CSV files are synthetic and intentionally small so a recruiter or reviewer can inspect the model quickly.

Files:

- `dim_unit.csv`: healthcare unit dimension.
- `dim_safety_target.csv`: patient safety target dimension.
- `fact_safety_walks.csv`: safety walk observation facts.
- `fact_notifications.csv`: patient safety notification facts.

The data is designed for SQL practice, Power BI modeling, KPI calculations, and portfolio demonstration only.
